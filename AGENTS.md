# Kaisen development guidance

Kaisen should feel like a premium futuristic command center: professional and highly usable first, with deliberate HUD, gaming, and Iron-Man-inspired energy.

- Preserve the dark graphite and cyan visual system.
- Prefer clear hierarchy and restrained motion over clutter.
- Keep all modules responsive and keyboard accessible.
- Use realistic mock data until integrations are explicitly requested.
- Run `npm run check` and `npm run build` before committing.
- Do not add databases, authentication, Ollama, n8n, Gmail, market APIs, or job APIs until their milestone is approved.
